SLIDE 2: APPLICATION OVERVIEW
===========================================
Title: Application Overview

Content:
- Mobile Sales Canvassing Application is a comprehensive field sales management system
- Designed to help sales representatives efficiently visit clients, take orders, and manage relationships
- Multi-role system supporting Admin, Manager, Supervisor, and Sales Representative roles
- Real-time GPS tracking and location-based features
- Complete sales cycle management from visit planning to payment collection

SLIDE 3: USER ROLES & ACCESS CONTROL
===========================================
Title: User Roles & Access Control

Content:
- Admin: Full system access, manage all users, outlets, and system configuration
- Manager: Team management, assign outlets, monitor team performance, view analytics
- Supervisor: Monitor team activities, view reports, assist with team coordination
- Sales Representative: Field operations, visit outlets, take orders, collect payments
- Role-based access control with JWT authentication
- Secure password management with bcrypt hashing

SLIDE 20: TECHNICAL ARCHITECTURE
===========================================
Title: Technical Architecture

Content:
- Frontend: Flutter framework with Dart
- Backend: Node.js with Express.js
- Database: PostgreSQL
- Authentication: JWT tokens
- Security: Helmet, Rate Limiting, CORS
- File Handling: Multer for uploads
- Excel Processing: XLSX library
- Location Services: Geolocator
- Maps: OpenStreetMap integration
- State Management: Provider pattern

===========================================
SLIDE 22: API ENDPOINTS - SALES REPS
===========================================
Title: API Endpoints - Sales Representatives

Content:
- GET /api/admin/sales-reps - List all sales reps
- POST /api/admin/sales-reps - Add new sales rep
- GET /api/admin/sales-reps/:id - Get sales rep details
- PUT /api/admin/sales-reps/:id - Update sales rep
- DELETE /api/admin/sales-reps/:id - Deactivate sales rep
- GET /api/admin/sales-reps/:id/dashboard - Get rep dashboard data
- GET /api/admin/sales-reps/:id/location - Get rep location
- GET /api/admin/sales-reps/:id/orders - Get rep orders
- GET /api/admin/sales-reps/:id/payments - Get rep payments
- GET /api/admin/sales-reps/:id/analytics - Get rep analytics

===========================================
SLIDE 23: API ENDPOINTS - OUTLETS
===========================================
Title: API Endpoints - Outlets

Content:
- GET /api/outlets - List outlets (filtered by role)
- POST /api/outlets - Create new outlet
- GET /api/outlets/:id - Get outlet details
- PUT /api/outlets/:id - Update outlet
- DELETE /api/outlets/:id - Delete outlet
- GET /api/admin/sales-reps/:id/outlets - Get assigned outlets
- GET /api/admin/sales-reps/:id/available-outlets - Get unassigned outlets
- POST /api/admin/sales-reps/:id/assign-outlet - Assign outlet to rep
- DELETE /api/admin/sales-reps/:id/remove-outlet/:outlet_id - Remove outlet assignment
