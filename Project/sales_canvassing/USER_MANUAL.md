## Application Overview

The Mobile Sales Canvassing Application is a comprehensive field sales management system designed to help sales representatives efficiently visit clients, take orders, manage relationships, and track performance. The application provides real-time GPS tracking, order management, stock control, payment collection, and comprehensive analytics.

**Key Features:**
- Real-time GPS tracking and location-based visit management
- Order taking with product catalog and shopping cart
- Stock management with Excel import/export
- Payment collection and tracking
- Outlet management and assignment
- Route planning and optimization
- Analytics and performance reporting
- Merchandising and planogram management
- Multi-role system with role-based access

## Getting Started

### Installation

1. **Download the App:**
   - Android: Download APK from provided link or Google Play Store
   - iOS: Download from App Store (when available)

2. **First-Time Setup:**
   - Open the app
   - You will see the login screen
   - Enter your credentials provided by your administrator
   - Tap "Login" to access the app

3. **Permissions:**
   - The app will request location permissions (required for GPS tracking)
   - Grant location permissions to enable visit check-in and GPS features
   - The app may request storage permissions (for Excel file handling)

### System Requirements

**Minimum Requirements:**
- Android 6.0 (API level 21) or higher
- iOS 12.0 or higher
- 2GB RAM
- 100MB free storage space

**Recommended:**
- Android 10.0 or higher
- iOS 14.0 or higher
- 4GB RAM
- 200MB free storage space
- GPS-enabled device
- Active internet connection

## Sales Representative Guide

### Daily Workflow

#### 1. Starting Your Day

**Step 1: Login**
- Open the app
- Enter your username and password
- Tap "Login"

**Step 2: Check Dashboard**
- Review today's visit schedule
- Check pending tasks
- Review yesterday's performance
- Note any urgent notifications

**Step 3: Plan Your Route**
- Open "Route Planning" screen
- Review assigned outlets for the day
- Optimize route if needed
- Note outlet priorities and special requirements

#### 2. Conducting Visits

**Step 1: Navigate to Outlet**
- Open "GPS Tracking" screen
- Select the outlet from your list
- Use navigation to reach the location
- Enable GPS for accurate tracking

**Step 2: Check-In**
- Arrive at the outlet location
- Open "Visits" screen
- Find the scheduled visit
- Tap "Check-In"
- GPS will verify your location
- Confirm check-in when prompted

**Step 3: Take Orders**
- Open "Order Taking" screen
- Browse product catalog
- Add items to cart
- Set quantities and prices
- Apply discounts if applicable
- Review order summary
- Submit order

**Step 4: Collect Payments**
- Open "Collections" screen
- View outstanding payments
- Record payment received
- Select payment method (cash, transfer, check)
- Update payment records

**Step 5: Merchandising (if applicable)**
- Open "Merchandising" screen
- Check planogram compliance
- Take photos of displays
- Record competitor activity
- Complete merchandising checklist
- Submit merchandising report

**Step 6: Check-Out**
- Return to "Visits" screen
- Tap "Check-Out" for the visit
- Add visit notes if needed
- Confirm check-out

#### 3. End of Day

**Step 1: Review Performance**
- Open "Analytics" screen
- Review daily sales figures
- Check visit completion rate
- View payment collections
- Note any issues or achievements

**Step 2: Update Stock (if applicable)**
- Open "Stock Management" screen
- Update stock levels
- Upload stock data via Excel if needed
- Report any stock issues

**Step 3: Sync Data**
- Ensure all data is synchronized
- Check for any pending uploads
- Verify orders are submitted
- Confirm payments are recorded

#### Visits Screen

**Purpose:** Manage outlet visits and check-in/check-out

**Features:**
- List of scheduled visits
- Visit status indicators
- Check-in/check-out functionality
- Visit history
- Visit notes

**How to Use:**
1. View all scheduled visits for the day
2. Each visit shows:
   - Outlet name and address
   - Scheduled time
   - Visit status (Planned, In Progress, Completed, Missed)
   - Distance from current location
3. Tap a visit to see details
4. Tap "Check-In" when you arrive at the outlet
5. GPS will verify your location
6. After completing the visit, tap "Check-Out"
7. Add notes about the visit if needed

**Visit Status Meanings:**
- **Planned:** Scheduled but not started
- **In Progress:** Checked in, visit ongoing
- **Completed:** Checked out, visit finished
- **Missed:** Scheduled but not completed

**Tips:**
- Always check-in when you arrive
- Check-out even if no order was taken
- Add detailed notes for missed visits
- Use GPS for accurate location verification

The Admin Dashboard provides comprehensive oversight of the entire sales operation.

**Key Features:**

### Managing Sales Representatives

#### Adding a New Sales Representative

1. Navigate to "Sales Representatives" in the dashboard
2. Tap "Add New Representative"
3. Fill in the required information:
   - Name
   - Email
   - Phone number
   - Username
   - Password
   - Position/Role
4. Assign to a team
5. Tap "Save" to create the account

#### Editing Sales Representative Information

1. Navigate to "Sales Representatives"
2. Tap on the representative to edit
3. Update the information as needed
4. Tap "Save" to apply changes

#### Deactivating a Sales Representative

1. Navigate to "Sales Representatives"
2. Tap on the representative
3. Tap "Deactivate"
4. Confirm deactivation
5. The representative will no longer be able to login

#### Viewing Representative Performance

1. Navigate to "Sales Representatives"
2. Tap on the representative
3. View performance metrics:
   - Total visits completed
   - Total sales amount
   - Average order value
   - Visit completion rate
   - Payment collection rate

### Managing Outlets

#### Adding a New Outlet

1. Navigate to "Outlets" in the dashboard
2. Tap "Add New Outlet"
3. Fill in outlet information:
   - Outlet code
   - Outlet name
   - Address
   - GPS coordinates (use map to select)
   - Owner name
   - Phone number
   - Credit limit
   - Priority level (A, B, C)
   - Store type
4. Tap "Save" to create the outlet

#### Assigning Outlets to Sales Representatives

1. Navigate to "Sales Representatives"
2. Tap on the representative
3. Tap "Assign Outlets"
4. Select outlets from the available list
5. Set visit dates and times
6. Tap "Save" to complete assignment

#### Removing Outlet Assignments

1. Navigate to "Sales Representatives"
2. Tap on the representative
3. Tap "Assigned Outlets"
4. Select the outlet to remove
5. Tap "Remove Assignment"

## Troubleshooting

### Common Issues and Solutions

#### Login Issues

**Problem:** Cannot login to the app

**Solutions:**
- Verify username and password are correct
- Check internet connection
- Ensure app is up to date
- Contact administrator if password is forgotten
- Check if account is active

**Problem:** App crashes on login

**Solutions:**
- Restart the app
- Clear app cache
- Update to latest version
- Reinstall the app
- Contact support if issue persists

#### GPS Issues

**Problem:** GPS not working

**Solutions:**
- Ensure location permissions are granted
- Check if GPS is enabled on device
- Move to area with better GPS signal
- Restart the app
- Check if location services are enabled in device settings

**Problem:** Check-in fails due to location

**Solutions:**
- Ensure you are at the correct location
- Wait for GPS to get accurate fix
- Move to open area for better GPS signal
- Check if outlet coordinates are correct
- Contact supervisor if coordinates are wrong

#### Order Issues

**Problem:** Cannot submit order

**Solutions:**
- Check internet connection
- Verify all required fields are filled
- Ensure cart is not empty
- Check if products are in stock
- Try again after a few moments
- Contact support if issue persists

**Problem:** Order not appearing in system

**Solutions:**
- Check if order was successfully submitted
- Verify internet connection was stable
- Sync data manually in settings
- Check order history in app
- Contact support if order is missing

#### Sync Issues

**Problem:** Data not syncing

**Solutions:**
- Check internet connection
- Pull to refresh on dashboard
- Manually sync in settings
- Ensure server is running
- Clear app cache and retry

**Problem:** Slow sync performance

**Solutions:**
- Check internet speed
- Close other apps using bandwidth
- Sync during off-peak hours
- Ensure device has sufficient storage
- Contact support if issue persists

#### Payment Issues

**Problem:** Payment not recording

**Solutions:**
- Verify payment amount is correct
- Check internet connection
- Ensure payment method is selected
- Try submitting again
- Contact supervisor if issue persists

**Problem:** Outstanding balance incorrect

**Solutions:**
- Verify payment history
- Check if all payments are recorded
- Contact admin to verify balance
- Report discrepancy to supervisor

### Getting Help

**In-App Help:**
- Navigate to Settings → Help
- Browse help topics
- Search for specific issues
- View FAQs

**Contacting Support:**
- Note the error message
- Describe what you were doing
- Include screenshots if possible
- Contact your supervisor or admin
- Provide device and app version information
